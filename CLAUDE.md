# Кодовая комната — правила работы

- Общение и документация — по-русски. Идентификаторы кода — как есть.
- Продукт — `PRODUCT.md`, дизайн-система — `DESIGN.md` (после выбора витрины), что вышло — `CHANGELOG.md`.
- **Задачи ведутся в трекере (проект CR), не в `TASKS.md`:**
  `node /Users/Denis/Work/task-tracker/bin/tt.js <команда> -p CR --as claude` или MCP `task-tracker`.
  Взял задачу — в «В работе»; прогресс — `comment`; итог — `review` (что сделано, как проверено,
  какие коммиты). Вопрос к Денису — `block`. Новая работа — сразу `add`, с эпиком:
  код эпика — префикс кода задачи (`PY.6` → `PY`), `tt add "…" --code PY.6 --epic PY`.
- **Коммиты** — Conventional Commits 1.0.0, описание по-русски, код задачи в scope или теле:
  `feat(python): вывод потоком и пояснения к ошибкам` + `PY.2` в теле.
- **Ветки — три уровня всегда:** `release/<версия>` → `epic/<имя>` → `feature|fix|docs/<имя>`.
  Фича мёржится в эпик, эпик — в релиз, релиз — в `main` с тегом `vX.Y.Z`. Мёрджи `--no-ff`.
  Прямо в релиз и эпик ничего не коммитим, только мёрджи. Имя ветки говорит, что делается.
- **Деплой — только тегом** из `main`: пуш тега выкатывает сайт на GitHub Pages.
  Закрытие релиза: проверки → раздел в `CHANGELOG.md` → версия в `package.json` → мёрдж → тег.
- **Интерфейс — только через скилл `impeccable`**, до разметки, а не после.
  **Новый экран начинается с витрины трёх вариантов** (`preview/<что>-variants.html`) на живых данных,
  под каждым — чем лучше и чем платит. Выбор за Денисом, до выбора боевой экран не трогаем.
- **Ответов в репозитории нет.** Сайт публичный: у задачи только условие, картинка, файлы, заготовка.
- **Задачи — экспортом из `Teaching/informatics`** (`tools/export_lesson.py --all`); правка руками в `public/lessons`
  затирается следующим экспортом. ЕГЭ-часть занятия — `Занятие NN …/Исходники/room_tasks.py` (`CLASS`, `HOME`).
  Подготовил занятие — выгрузил и выпустил релиз, иначе в комнате его нет (README, «Задачи занятий»).
- К ученику — на «ты», простыми словами.
- Перед мёрджем: `npm run typecheck && npm test && npm run e2e`; интерфейс — глазами в браузере.
