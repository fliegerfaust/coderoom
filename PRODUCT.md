## Platform

web

## Stack
Vite + TypeScript, как в игре Starweave. Статический сайт на GitHub Pages, выкатка тегом версии.
Python исполняется в браузере (Pyodide в Web Worker, файлы лежат на самом сайте). Совместное
редактирование построено на Yjs; синхронизацию держит Firebase Realtime Database (бесплатный
тариф), своего сервера нет. Репозиторий: `/Users/Denis/Work/coderoom`.

## Users
- **Денис Валерьевич, преподаватель.** Ведёт информатику только индивидуально, онлайн: на связи
  (Контур.Толк), с доской Holst и с этой комнатой. Показывает, как пишется код, смотрит, как
  пишет ученик, и подсказывает по ходу.
- **Ученик, сейчас один: Аршак, 11 класс.** Готовится к ЕГКР в декабре и к ЕГЭ-2027 сам, учителя
  информатики в школе нет. Python знает слабо. На занятии код пишет сам, вместе с преподавателем.

## Product Purpose
«Кодовая комната» — одна страница на занятие: слева условие задачи, справа общий редактор Python,
под ним вывод. Код пишут оба сразу, каждый видит курсор другого, запуск виден обоим. Комната
заменяет связку «IDLE у ученика + демонстрация экрана + копирование кода из плана».
Успех: занятие проходит без переключения окон, ученик пишет код сам, а преподаватель видит
каждую строку в момент, когда она набирается.

## Positioning
Совместные редакторы (Replit, Live Share) и онлайн-интерпретаторы не держат рядом с кодом условие
задачи из программы занятия. Комната показывает задачи из материалов Дениса (атомы «Азы Python»
и задачи ЕГЭ по образцу ФИПИ) и не требует от ученика ни аккаунта, ни установки.

## Operating Context
- Занятие 60 минут, онлайн. Параллельно открыты связь и доска Holst, где лежат карточки и домашка.
- Устройство: в приоритете ноутбук или ПК, кодят только на них. Телефон — запасной вариант:
  на нём должно быть удобно хотя бы читать и запускать.
- Материалы занятий лежат в `Teaching/informatics`: папка на занятие, задачи считаются кодом
  в `Исходники`. Комната берёт задачи оттуда экспортом и не становится вторым источником правды.
- Домашка остаётся на доске Holst и проверяется вручную. Платформы для информатики нет,
  и комната ею не становится.

## Capabilities and Constraints
- Вход без аккаунтов: секретная ссылка на комнату плюс PIN, который преподаватель называет
  на занятии. Вход через Яндекс ID отложен до появления второго ученика.
- Сайт на GitHub Pages публичный. Поэтому **ответы и разборы в репозиторий не попадают**:
  у задачи на сайте есть условие, картинка, файлы и заготовка кода, но нет ответа.
- Код и вывод комнаты лежат в Firebase по пути, который вычисляется из комнаты и PIN.
  Без PIN путь не узнать.
- Python в браузере: `input()` берёт строки из поля «Ввод», файлы к задаче (№9, №17, №24, №26,
  №27) кладутся рядом с программой. Долгую программу можно остановить.
- Не решено: нужна ли проверка ответа в комнате (это приблизило бы её к платформе).

## Product Principles
1. Ученик пишет код сам. Комната помогает видеть и подсказывать, а не подсовывает готовое.
2. Ничего лишнего на экране: задача, код, вывод. Каждая кнопка нужна на занятии.
3. Один источник правды для задач — материалы занятия в `informatics`.
4. Ученику ничего не нужно ставить и заводить: ссылка, PIN, имя.
5. Ответы не уходят в публичную сеть.
